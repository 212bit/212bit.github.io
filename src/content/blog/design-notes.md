[建站记](/blog/hello-this-blog/) 讲了为什么选 Astro 和 GitHub Pages，这篇讲另一件我更在意的事：它长什么样，以及为什么长这样。全部实现就是一个 831 行的 `global.css` 加几个组件——没有 UI 框架，没有运行时 JavaScript。

## 起点：反「模板脸」

大多数技术博客长一个样：白底、蓝色链接、圆角卡片网格。好看是好看，但一万个人用就长一万零一个样。我给自己定了三个约束：**可辨识**（三秒内记住它）、**可维护**（设计系统一份文件说清）、**零 JavaScript**（内容站不需要运行时）。

概念最终收敛成三个字：纸上手记——把博客当成一本装帧讲究的笔记本来排。三样东西：纸、墨、印。

## 设计系统：变量先行，暗色免费

全部颜色收进 `:root` 的十来个变量，组件只引用 token、不写色值：

```css
:root {
  --paper: #f6f1e7;        /* 暖纸底 */
  --ink: #23201b;          /* 墨色 */
  --seal: #bc3a1d;         /* 朱砂：全站唯一强调色 */
  --line: rgba(35, 32, 27, 0.16);
}
@media (prefers-color-scheme: dark) {
  :root {
    --paper: #1a1713;
    --ink: #ece4d6;
    --seal: #e0603c;
    --line: rgba(236, 228, 214, 0.17);
  }
}
```

暗色模式就是**换一组变量值**——跟随系统、零 JS、没有主题切换按钮，自然也没有闪白。最大的收益是纪律：「全站只有一种红」这条规则被变量本身锁死了，想加第二种强调色，你得先说服自己为什么破坏它。

## 纸张的质感：一层几乎看不见的噪点

纯色底没有「纸感」。做法是一层 SVG 噪点（`feTurbulence`）做固定覆盖层，`opacity: 0.05`，亮色用 `multiply` 混合、暗色换成 `screen`。它存在的标准很明确：**盯着看发现不了，划过时手感能对**。加上 `pointer-events: none`，不挡任何交互。

## 字体栈：西文上网络，中文交系统

- **西文展示**：Fraunces（可变字重 + 光学尺寸轴），词标 212bit 用它的斜体，编辑部气质的来源；
- **中文标题**：Noto Serif SC（Google Fonts 按 unicode-range 切片、按需下载），本机回退宋体——标题用衬线才有「手记」的版面感；
- **正文**：不加载任何 webfont，PingFang SC / 微软雅黑系统栈直接上。中文 webfont 动辄几 MB，而系统字体已经足够好，正文要的是舒适不是表演；
- **元信息**：IBM Plex Mono——日期、标签、列表编号、导航，全部交给等宽字体，档案卡片的感觉。

CJK 排版另有几个容易被忽略的细节：行高放到 1.85（中文需要更松的呼吸）、正文列宽 42rem 封顶（长行是中文阅读杀手）、h2 前面一条朱砂小杠代替纯文字层级、分隔线不用 `<hr>` 默认样式而是居中的 ⁂。

## 代码高亮：构建期双主题

代码块用 Shiki 在**构建期**高亮（零运行时成本）。要同时伺候亮暗两种系统外观，用它的双主题模式：`vitesse-light` 配 `vitesse-dark`，输出两套 CSS 变量，切换只是一段媒体查询：

```css
@media (prefers-color-scheme: dark) {
  .prose .astro-code, .prose .astro-code span {
    color: var(--shiki-dark) !important;
  }
}
```

## 印章与动效：克制到只剩两处

页头那枚「记」字印章，靠不规则圆角加 6 度旋转模拟手钤的歪斜，favicon 是同一枚——全站最「花」的元素就它了。动效只保留一处：首页加载时的一次错峰浮现（几个 `animation-delay`），且 `prefers-reduced-motion` 下直接关闭。**动效的预算花在一个高光时刻，比撒在十处 hover 上有效。**

## 内容管道：类型即验收

文章走 Astro 内容集合：glob loader 加载 Markdown，zod schema 校验 frontmatter——`date` 写错格式、漏了 `description`，构建直接失败。**错误的文章进不了发布管道**，这比任何后台的表单校验都可靠。

排序规则是「日期倒序、同日期按 slug 决胜」——后半句是上线首周翻车（同日期文章顺序漂移）换来的，详细复盘在[开发手记（二）](/blog/agent-dev-2-drift/)里。

## 踩坑两枚

一是 CommonMark 的中文加粗边界：`**加粗**` 的闭合符号若紧跟中文字符、且前方是标点（比如「（master）**只」），星号会原样显示——CJK 字符在强调规则里被当作普通字母处理。修法是给闭合后接标点或空格。二是整页截图工具对 sticky 页头会产生拼接伪影，看着像布局坏了，其实是截图的病——**验收别只信一种工具**。

## 结尾

全部设计决策就这些：纸、墨、印；变量先行、零 JS、构建期高亮。源码就在[仓库](https://github.com/212bit/212bit.github.io)里，`global.css` 改几个变量就能换成你自己的气质——这本来就是它的用法。
